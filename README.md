# 皇冠·卡牌战斗

回合制卡牌对战 + 肉鸽（Roguelike）构筑。纯前端，无框架，原生 JS + CSS + HTML。

## 玩法

- **快速战斗**：选英雄、选对手，直接开打。
- **征途**：12 节点 run —— 战斗 8 · 商人 2 · 营地 1 · BOSS 1。
  胜利得碎片 + 免费改造 ×1；商人按碎片买改造（同一商人连买 +50% 涨价）；
  失败即结束。碎片结算换皇冠（800 碎片 = 1 皇冠），皇冠买永久技能。
- **图鉴**：44 英雄 · 177 卡 · 10 关键词 · 40 机制簇 · 13 改造 · 12 永久技能。

## 结构

```
index.html      入口
style.css       全局样式（含窄屏适配）
data/
  heroes.js     44 名英雄 + 关键词表 + 机制簇表
  cards.js      177 张卡（通用池 + 专属卡）+ 卡组构筑
engine.js       战斗引擎（出牌 / 攻击 / 技能 / 回合 / 终局）
ai.js           贪心 AI（斩杀优先 → 解场 → 出牌 → 攻击）
roguelike.js    肉鸽层（节点 / 改造 / 商店 / 永久技能）
app.js          界面（大厅 · 战斗 · 征途 · 商人 · 改造 · 图鉴 · 技能树）
test.js         Node 冒烟测试
```

## 术语

| 术语 | 含义 |
|---|---|
| 费用 / cost | 打出卡牌所需的产出 |
| 产出 / prod | 本回合可用产出，每回合按 `prod1 + (turns-1) * prodGrowth` 增长 |
| 承受力 / load | 战场满编数 |
| 承受值 / armor | 卡牌师护甲，先于生命吸收伤害 |
| 攻击 / atk · 生命值 / hp | 单位数值 |
| 手牌上限 / handMax | 满手后抽牌销毁 |
| 疲劳 / fatigue | 牌库抽空后每回合递增伤害 |

关键词：嘲讽 · 冲锋 · 火炮 · 亡语 · 圣盾 · 吸血 · 驱散 · 光环 · 过牌 · 终端
